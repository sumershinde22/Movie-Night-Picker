# This document:

- Lists the 4 tasks I required participants to do as part of the usability study recordings
- Lists notes pertaining to the participants' experiences in executing said tasks
- Breaks down the participants' feedback into actionable changes that need to be made to the overall app.

# Main tasks - use cases: (specific, measurable, concrete)

A user should be able to make an account and add 3 movies to their profile
A user should be able to create a movie night with at least 3 candidate movies, finish voting, and spin the tiebreaker wheel at the end
A user should be able to invite me to a movie night and finish voting
A user should be able to join my movie night and finish voting

# Actionable Tasks

1. Pop an alert window upon creation of movie night, informing the user that all non-watched movies of the users they added to their movie night will appear in the voting panel, and also informing them of their selected movie filters.
   - This will help to avoid confusion when accidentally adding offline users, and avoid confusion for why a movie isn't showing up in the movie night.
2. Improve the visibility of the top nav items.
   - This will help users understand how to create a new movie night.
3. Add a text box to explain how to use the app.
   - This will prevent a lot of general confusion, such as why newly added movies aren't showing up in a movie night.
4. Add a button to a movie night for the host to immediately end the movie night
   - This will allow finishing movie nights in scenarios where a participant (including an offline participant) loses connection, or for whatever reason is unable to finish casting their votes.
